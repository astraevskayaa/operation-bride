# Приглашение на девичник

Готовый одностраничный сайт-приглашение.

## Как опубликовать на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория файлы:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Нажмите **Save**.
6. Через несколько минут GitHub покажет ссылку на сайт.

## Что можно изменить

Основной текст находится в `index.html`.

Дата и время сейчас указаны так:
- 1 августа
- 15:30

Цвета и оформление находятся в `styles.css`.
