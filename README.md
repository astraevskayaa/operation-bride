# Сайт-приглашение на девичник

Готовый одностраничный сайт в кавказско-армянском комедийном стиле.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите в корень репозитория:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Откройте **Settings → Pages**.
4. Выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Нажмите **Save**.
