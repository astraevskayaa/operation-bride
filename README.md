# Приглашение — решение семейного совета

Обновлённый сайт в стиле дорогой бордовой кожаной папки с золотым тиснением.

## В архиве

- `index.html`
- `styles.css`
- `script.js`

## Публикация на GitHub Pages

1. Замените старые `index.html`, `styles.css` и `script.js` в репозитории.
2. Сделайте commit.
3. Если GitHub Pages уже включён, сайт обновится автоматически.
